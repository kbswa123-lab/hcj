# 교육자료신청

Google Apps Script(GAS)로 제작한 **교육자료신청 웹앱**입니다.  
사용자가 이름, 이메일, 교수님께 하고 싶은 말을 입력하면 Google 스프레드시트에 신청 내용을 저장하고, 접수가 완료되면 안내 화면을 표시합니다.

## 주요 기능

- 이름 입력
- 이메일 입력
- 교수님께 하고 싶은 말 작성
- Google 스프레드시트에 신청 정보 저장
- 입력값 검증
- 신청 처리 중 버튼 비활성화
- 오류 발생 시 오류 메시지 표시
- 신청 완료 화면 표시
- PC 및 모바일 반응형 화면 지원

## Code.gs

`Code.gs`는 Google Apps Script의 서버 측 코드입니다.

웹앱 접속 시 `doGet()`을 통해 `index.html`을 불러오며, `submitApplication(data)`에서 신청 데이터를 Google 스프레드시트에 저장합니다. fileciteturn1file1L6-L12

### 스프레드시트 ID 설정

다음 부분에 사용할 Google 스프레드시트의 ID를 입력해야 합니다.

```javascript
const SPREADSHEET_ID = '여기에_구글_스프레드시트_ID를_입력하세요';
```

실제 Google 스프레드시트 ID로 변경한 후 사용하세요. fileciteturn1file1L4-L4

### 저장되는 데이터

신청 데이터는 스프레드시트의 첫 번째 시트에 다음 순서로 저장됩니다.

| 열 | 내용 |
|---|---|
| A | 이름 |
| B | 이메일 |
| C | 교수님께 하고 싶은 말 |

서버 코드는 입력 데이터를 정리한 뒤 첫 번째 시트에 한 행씩 추가합니다. fileciteturn1file1L12-L15 fileciteturn1file1L25-L32

## index.html

`index.html`은 사용자가 실제로 보는 교육자료신청 화면입니다.

화면 제목은 **교육자료신청**이며, 교육자료를 받기 위해 필요한 내용을 입력하도록 구성되어 있습니다. fileciteturn1file0L215-L223

### 입력 항목

#### 1. 이름

사용자의 이름을 입력합니다.

필수 입력 항목이며 입력하지 않고 제출하면 서버에서 `이름을 입력해주세요.`라는 오류를 발생시킵니다. fileciteturn1file0L223-L234 fileciteturn1file1L17-L19

#### 2. 이메일

교육자료를 받을 이메일 주소를 입력합니다.

HTML의 `email` 입력 형식을 사용하며 필수 입력 항목입니다. fileciteturn1file0L236-L246

서버에서도 이메일 입력 여부를 확인합니다. 입력하지 않은 경우 `이메일을 입력해주세요.`라는 오류가 표시됩니다. fileciteturn1file1L21-L23

#### 3. 교수님께 하고 싶은 말

교수님께 전달하고 싶은 내용을 자유롭게 작성할 수 있는 입력창입니다. fileciteturn1file0L248-L254

## 신청 처리 과정

```text
사용자가 이름 입력
       ↓
이메일 입력
       ↓
교수님께 하고 싶은 말 입력
       ↓
「확인」 버튼 클릭
       ↓
신청 데이터 생성
       ↓
Google Apps Script 서버 호출
       ↓
Google 스프레드시트에 저장
       ↓
신청 완료 화면 표시
```

웹페이지에서는 `google.script.run`을 이용해 `submitApplication(data)` 함수를 호출합니다. fileciteturn1file0L281-L308

## 신청 완료 화면

신청이 정상적으로 처리되면 입력 화면이 숨겨지고 다음 안내가 표시됩니다.

> 오늘 교육 받느라  
> 수고하셨습니다.

추가로 `신청이 정상적으로 접수되었습니다.`라는 안내가 표시됩니다. fileciteturn1file0L265-L269

서버에서는 성공 여부를 다음과 같이 반환합니다.

```javascript
return {
  success: true,
  message: '오늘 교육 받느라 수고하셨습니다.'
};
```

## 오류 처리

신청 중 문제가 발생하면 화면에 오류 메시지를 표시하고, 제출 버튼을 다시 사용할 수 있도록 활성화합니다.

또한 신청 처리 중에는 버튼의 문구가 `저장 중...`으로 변경되고 버튼이 비활성화됩니다. fileciteturn1file0L284-L286

## Google 스프레드시트 준비

1. Google 스프레드시트를 새로 만듭니다.
2. 스프레드시트의 ID를 확인합니다.
3. `Code.gs`의 `SPREADSHEET_ID`에 ID를 입력합니다.
4. 첫 번째 시트를 신청 데이터 저장용으로 사용합니다.
5. 필요하다면 첫 번째 행에 다음과 같은 제목을 작성할 수 있습니다.

```text
이름 | 이메일 | 교수님께 하고 싶은 말
```

## Google Apps Script 배포 방법

1. Google Apps Script에서 새 프로젝트를 생성합니다.
2. `Code.gs` 파일에 서버 코드를 입력합니다.
3. `index.html` 파일을 생성합니다.
4. `index.html` 내용을 입력합니다.
5. `SPREADSHEET_ID`를 실제 스프레드시트 ID로 변경합니다.
6. **배포 → 새 배포**를 선택합니다.
7. 배포 유형에서 **웹 앱**을 선택합니다.
8. 실행 권한 및 접근 권한을 설정합니다.
9. 배포합니다.
10. 생성된 웹앱 URL로 접속하여 신청 테스트를 진행합니다.

`doGet()`은 `index.html`을 불러오고 웹페이지 제목을 `교육자료신청`으로 설정하도록 작성되어 있습니다. fileciteturn1file1L6-L10

## 주의사항

- `Code.gs`의 `SPREADSHEET_ID`를 반드시 실제 스프레드시트 ID로 변경해야 합니다.
- `Code.gs`와 `index.html`의 파일 이름을 임의로 변경하지 않는 것을 권장합니다.
- `doGet()` 함수가 있어야 GAS 웹앱으로 정상 실행할 수 있습니다.
- 스프레드시트에 데이터를 기록할 수 있도록 Google Apps Script에 필요한 권한을 승인해야 합니다.
- 현재 코드는 첫 번째 시트를 데이터 저장 대상으로 사용합니다.
- 실제 배포 전에 이름, 이메일 입력 및 스프레드시트 저장 여부를 테스트하는 것을 권장합니다.
