# 교육만족도 설문조사

Google Apps Script(GAS)로 제작한 교육만족도 설문조사 웹앱입니다.

## 주요 기능

- 이름 입력
- 교육만족도 1~5점 선택
- 가장 도움이 된 내용 작성
- Google 스프레드시트에 설문 결과 저장
- 제출 완료 후 감사 메시지 표시
- PC와 모바일 화면에 대응하는 반응형 디자인
- 선택하지 않은 만족도에 대한 안내 메시지 표시
- 제출 중 버튼 비활성화 처리 및 오류 메시지 표시

## 파일 구성

```text
프로젝트/
├── Code.gs
├── index.html
└── README.md
```

### Code.gs

웹앱을 실행하기 위한 서버 측 Google Apps Script 코드입니다.

`doGet()`은 `index.html`을 웹페이지로 불러오며, `submitSurvey(data)`는 설문 데이터를 Google 스프레드시트에 저장합니다.

현재 스프레드시트 ID는 다음 부분에 입력해야 합니다.

```javascript
const SPREADSHEET_ID = '여기에_구글_스프레드시트_ID';
```

실제 Google 스프레드시트 ID로 변경한 후 사용하세요.

## Google 스프레드시트 설정

설문 결과를 저장할 Google 스프레드시트를 준비합니다.

권장 첫 번째 행의 열 제목은 다음과 같습니다.

| A | B | C |
|---|---|---|
| 이름 | 교육만족도 | 가장 도움이 된 내용 |

`Code.gs`는 첫 번째 시트를 가져와 다음 세 가지 값을 한 행에 추가합니다.

- 이름
- 교육만족도
- 가장 도움이 된 내용

## index.html

사용자가 실제로 보는 설문조사 화면입니다.

### 입력 항목

1. **이름**
   - 이름을 입력합니다.
   - 필수 입력 항목입니다.

2. **교육만족도**
   - 1점부터 5점까지 선택할 수 있습니다.
   - 1점: 매우 불만족
   - 5점: 매우 만족
   - 선택하지 않고 제출하면 `교육만족도를 선택해주세요.`라는 안내가 표시됩니다.

3. **가장 도움이 된 내용**
   - 교육에서 가장 도움이 되었던 내용을 입력합니다.
   - 필수 입력 항목입니다.

## 설문 제출 과정

사용자가 `설문 제출` 버튼을 누르면 다음 순서로 동작합니다.

```text
설문 작성
   ↓
교육만족도 선택 여부 확인
   ↓
설문 데이터 생성
   ↓
Google Apps Script 서버 호출
   ↓
Google 스프레드시트에 데이터 저장
   ↓
제출 완료 화면 표시
```

제출이 완료되면 다음 메시지가 표시됩니다.

> 설문에 참여해주셔서 감사합니다.

## 디자인

화면은 카드 형태의 중앙 정렬 UI로 구성되어 있습니다.

- 밝은 배경
- 둥근 카드 디자인
- 1~5점 선택형 버튼
- 선택된 점수 강조 표시
- 모바일 반응형 지원
- 제출 중 상태 표시
- 오류 메시지 표시

CSS에서 라디오 버튼 자체는 숨기고, 연결된 `label`을 버튼처럼 표시하는 방식으로 만족도 선택 UI를 구현했습니다.

## Google Apps Script 배포 방법

1. Google Apps Script에서 새 프로젝트를 생성합니다.
2. 서버 코드에 `Code.gs` 내용을 붙여넣습니다.
3. HTML 파일을 `index.html`이라는 이름으로 생성합니다.
4. `index.html` 내용을 붙여넣습니다.
5. `Code.gs`의 `SPREADSHEET_ID`를 실제 스프레드시트 ID로 변경합니다.
6. **배포 → 새 배포**를 선택합니다.
7. 유형을 **웹 앱**으로 선택합니다.
8. 필요한 실행 권한과 접근 권한을 설정합니다.
9. 배포 후 생성된 웹 앱 URL로 접속합니다.

## 주의사항

- `Code.gs`와 `index.html`의 파일 이름을 임의로 변경하지 않는 것을 권장합니다.
- `doGet()` 함수가 반드시 `Code.gs`에 존재해야 합니다.
- 스프레드시트 ID를 정확하게 입력해야 데이터 저장이 정상적으로 작동합니다.
- 스프레드시트에 접근할 수 있는 권한이 Google Apps Script 실행 계정에 있어야 합니다.
- `index.html`은 Google Apps Script 웹앱에서 실행되는 것을 기준으로 작성되어 있으므로 `google.script.run`을 사용합니다.

## 현재 코드의 서버 응답 관련 참고

현재 `Code.gs`의 `submitSurvey(data)`는 마지막에 `true`를 반환합니다.

반면 `index.html`에서는 서버 응답이 객체이고 `result.success`가 `true`인지 확인하도록 작성되어 있습니다.

```javascript
if (result && result.success) {
```

따라서 실제 배포 시 제출 완료 처리를 확실하게 하려면 `Code.gs`의 반환값을 다음과 같이 변경하는 것을 권장합니다.

```javascript
return { success: true };
```

이 경우 `index.html`의 성공 처리와 정확하게 연결됩니다.
