Git & GitHub Guide

각 팀원 GitHub에 작업 올리기

MT 웹페이지 수정사항 및 각자의 후기를 개별 브랜치로 분기하여 Push & PR하는 표준 워크플로우입니다.

1

Clone & Branch 생성

공동 레포지토리를 클론하고 본인 이름으로 feature 브랜치를 생성합니다.

git clone <repo-url>
cd gyeongju-mt-2026
git checkout -b feat/member-name
2

수정 사항 Commit & Push

자신의 역할, 일정 피드백, 후기 마크다운을 작성한 뒤 커밋 규칙에 맞춰 푸시합니다.

git add .
git commit -m "docs: 경주 MT 일정 및 후기 추가"
git push origin feat/member-name
3

Pull Request & 코드 리뷰

GitHub 웹페이지에서 main 브랜치로 PR을 올리고 다른 팀원 2명 이상의 리뷰 후 머지합니다.

Title: [Member-1] 경주 코스 업데이트
Reviewers: 5인 팀원 지정
Merge: Squash & Merge

5인 팀 GitHub 커밋 컨벤션 템플릿

feat: 새로운 기능/페이지 추가 예: feat: 대릉원 사진 갤러리 섹션 추가
docs: 문서 및 마크다운 후기 수정 예: docs: 팀원 3 바비큐 재료 리스트 정리
fix: 버그 및 오타 수정 예: fix: 1/N 정산 계산 공식 오류 수정
style: UI/디자인 레이아웃 보정 예: style: 모바일 화면 카드 여백 조정
